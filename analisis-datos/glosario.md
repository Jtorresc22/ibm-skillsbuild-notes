# Glosario - Data Fundamentals

### 5 Por qué (EN: 5 Whys)
- **Definición:** Técnica que busca la causa raíz de un problema preguntando "por qué" unas cinco veces de forma encadenada.
- **Categoría:** técnica
- **Módulo:** DF-M02, DF-M03
- **Relacionado:** Causa raíz, Curiosidad

### 5 V (EN: 5 V)
- **Definición:** Cinco características de big data: volumen, variedad, velocidad, veracidad y valor.
- **Categoría:** concepto
- **Módulo:** DF-M01
- **Relacionado:** Big data, Volumen, Variedad, Velocidad, Veracidad, Valor

### Agrupamiento (EN: Clustering)
- **Definición:** Técnica que agrupa datos similares entre sí al analizarlos.
- **Categoría:** técnica
- **Módulo:** DF-M03
- **Relacionado:** Regresión, Clasificación

### Almacén de datos (EN: Data warehouse)
- **Definición:** Sistema destino donde se cargan datos integrados de varias fuentes.
- **Categoría:** herramienta
- **Módulo:** DF-M01
- **Relacionado:** ETL, Base de datos

### Análisis de datos (EN: Data analysis)
- **Definición:** Proceso de recopilar, limpiar y transformar datos para obtener información que apoye decisiones.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02
- **Relacionado:** Insights de datos, ETL, Decisiones basadas en datos

### Análisis descriptivo (EN: Descriptive analytics)
- **Definición:** Resume datos históricos y actuales para mostrar qué está pasando, sin explicar la causa.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02
- **Relacionado:** Análisis diagnóstico, Métricas de rendimiento

### Análisis diagnóstico (EN: Diagnostic analytics)
- **Definición:** Profundiza en los hallazgos descriptivos para identificar por qué ocurren.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02
- **Relacionado:** Análisis descriptivo, Análisis predictivo

### Análisis predictivo (EN: Predictive analytics)
- **Definición:** Usa datos históricos y modelos para estimar eventos, cantidades o momentos futuros.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02, DF-M05
- **Relacionado:** Modelo predictivo, Aprendizaje automático, Análisis prescriptivo

### Análisis prescriptivo (EN: Prescriptive analytics)
- **Definición:** Combina los análisis anteriores para determinar qué acciones tomar ante un problema o tendencia.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02
- **Relacionado:** Análisis predictivo, Aprendizaje automático

### Analista de datos (EN: Data analyst)
- **Definición:** Rol que examina grandes conjuntos de datos para hallar tendencias y comunicarlas con visualizaciones.
- **Categoría:** concepto
- **Módulo:** DF-M02, DF-M05
- **Relacionado:** Científico de datos, Ingeniero de datos

### Apache Hadoop (EN: Apache Hadoop)
- **Definición:** Herramienta de big data que los empleadores mencionan entre las habilidades adicionales del científico de datos.
- **Categoría:** herramienta
- **Módulo:** DF-M05
- **Relacionado:** Big data, Apache Spark

### Apache Spark (EN: Apache Spark)
- **Definición:** Motor de análisis multilenguaje de código abierto para datos muy grandes, en un nodo o en clústeres.
- **Categoría:** herramienta
- **Módulo:** DF-M03
- **Relacionado:** Big data, Scala

### Aprendizaje automático (EN: Machine learning)
- **Definición:** Conjunto de técnicas en que los sistemas aprenden de datos; apoya el análisis predictivo y prescriptivo y los flujos alimentados por ETL.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02, DF-M03, DF-M05
- **Relacionado:** Aprendizaje profundo, Modelo predictivo

### Aprendizaje no supervisado (EN: Unsupervised learning)
- **Definición:** Entrena modelos con grandes volúmenes de datos sin etiquetar para que los clasifiquen por sí solos.
- **Categoría:** técnica
- **Módulo:** DF-M02
- **Relacionado:** Aprendizaje supervisado, Aprendizaje automático

### Aprendizaje profundo (EN: Deep learning)
- **Definición:** Técnica avanzada a la que recurre a menudo el análisis predictivo.
- **Categoría:** técnica
- **Módulo:** DF-M01
- **Relacionado:** Aprendizaje automático

### Aprendizaje reforzado (EN: Reinforcement learning)
- **Definición:** Aprendizaje por ensayo y error con recompensas y penalizaciones, usado en vehículos autónomos y robótica.
- **Categoría:** técnica
- **Módulo:** DF-M02
- **Relacionado:** Aprendizaje supervisado, Aprendizaje automático

### Aprendizaje supervisado (EN: Supervised learning)
- **Definición:** Entrena modelos con ejemplos etiquetados para crear reglas generales aplicables a casos nuevos.
- **Categoría:** técnica
- **Módulo:** DF-M02, DF-M04
- **Relacionado:** Aprendizaje no supervisado, Entrenamiento de modelos

### Aprovisionamiento de servicio (EN: Service provisioning)
- **Definición:** Habilitar un servicio en la nube, como Watson Studio, para empezar a usarlo.
- **Categoría:** técnica
- **Módulo:** DF-M04
- **Relacionado:** IBM Cloud, IBM Watson Studio

### Archivo CSV (EN: Comma-separated values (CSV))
- **Definición:** Archivo de texto con valores separados por comas en el que cada fila es un registro.
- **Categoría:** herramienta
- **Módulo:** DF-M04
- **Relacionado:** Datos estructurados, Hoja de cálculo

### Asistente virtual (EN: Virtual assistant)
- **Definición:** Aplicación como Alexa o Siri que usa NLP para entender y procesar lenguaje humano en tiempo real.
- **Categoría:** herramienta
- **Módulo:** DF-M05
- **Relacionado:** Procesamiento del lenguaje natural

### Base de datos (EN: Database)
- **Definición:** Colección organizada de datos estructurados en un sistema informático, accesible mediante consultas.
- **Categoría:** herramienta
- **Módulo:** DF-M01, DF-M02, DF-M03
- **Relacionado:** Base de datos relacional, SQL, Datos estructurados

### Base de datos relacional (EN: Relational database)
- **Definición:** Base compuesta por varias tablas vinculadas entre sí mediante datos comunes.
- **Categoría:** herramienta
- **Módulo:** DF-M01, DF-M03
- **Relacionado:** Base de datos, SQL

### Biblioteca (EN: Library)
- **Definición:** Conjunto de código reutilizable de un lenguaje, como pandas o Matplotlib en Python.
- **Categoría:** concepto
- **Módulo:** DF-M03
- **Relacionado:** Python, Matplotlib, pandas

### Big data (EN: Big data)
- **Definición:** Datos masivos y complejos, a menudo de fuentes nuevas, que exigen procesamiento innovador; no tiene definición oficial única.
- **Categoría:** concepto
- **Módulo:** DF-M01, DF-M03
- **Relacionado:** 5 V, Datos no estructurados, Unidades de almacenamiento

### Booleano (EN: Boolean)
- **Definición:** Tipo de dato con dos valores, verdadero o falso.
- **Categoría:** tipo de dato
- **Módulo:** DF-M04
- **Relacionado:** Entero, Tipo de datos

### Cadena (EN: String)
- **Definición:** Tipo de dato formado por una secuencia de letras, dígitos y signos, como una dirección postal.
- **Categoría:** tipo de dato
- **Módulo:** DF-M04
- **Relacionado:** Conversión de tipo de columna, Tipo de datos

### Calidad de los datos (EN: Data quality)
- **Definición:** Grado de completitud, integridad y fiabilidad de los datos; se mejora al limpiarlos.
- **Categoría:** buena práctica
- **Módulo:** DF-M01, DF-M02, DF-M04, DF-M05
- **Relacionado:** Veracidad, ETL, Datos ruidosos

### Categoría (comparación) (EN: Category comparison)
- **Definición:** Relación de orden (mayor, menor o igual) entre elementos, como un ranking.
- **Categoría:** concepto
- **Módulo:** DF-M01
- **Relacionado:** Proporción relativa, Gráfico de barras

### Causa raíz (EN: Root cause)
- **Definición:** Origen fundamental de un problema, que se busca con la técnica de los 5 Por qué.
- **Categoría:** concepto
- **Módulo:** DF-M02
- **Relacionado:** 5 Por qué

### Ciencia de datos (EN: Data science)
- **Definición:** Enfoque multidisciplinario que combina método científico, estadística, programación e IA para extraer información accionable de los datos.
- **Categoría:** concepto
- **Módulo:** DF-M02
- **Relacionado:** Método científico, Inteligencia artificial, Análisis de datos

### Científico de datos (EN: Data scientist)
- **Definición:** Rol que diseña procesos de modelado, usa algoritmos y análisis predictivo y define el enfoque analítico.
- **Categoría:** concepto
- **Módulo:** DF-M02, DF-M05
- **Relacionado:** Analista de datos, Ciencia de datos

### Clasificación (EN: Classification)
- **Definición:** Técnica de análisis que asigna datos a categorías.
- **Categoría:** técnica
- **Módulo:** DF-M03
- **Relacionado:** Regresión, Agrupamiento

### Cloud Object Storage (EN: Cloud Object Storage (COS))
- **Definición:** Almacenamiento de un proyecto de Watson Studio, apto para datos no estructurados como imágenes y texto.
- **Categoría:** herramienta
- **Módulo:** DF-M04
- **Relacionado:** IBM Watson Studio, Datos no estructurados

### Código abierto (EN: Open source software)
- **Definición:** Software con código público que una comunidad puede usar, ver, modificar y compartir bajo licencia.
- **Categoría:** concepto
- **Módulo:** DF-M03
- **Relacionado:** Licencia de software, Comunidad, Git

### Código de conducta (EN: Code of conduct)
- **Definición:** Pautas que protegen a la comunidad de un proyecto y definen el comportamiento aceptable.
- **Categoría:** buena práctica
- **Módulo:** DF-M03
- **Relacionado:** Comunidad, Pautas de contribución

### Colaborador (EN: Contributor)
- **Definición:** Persona que contribuye a un proyecto de código abierto.
- **Categoría:** concepto
- **Módulo:** DF-M03
- **Relacionado:** Committer, Comunidad

### Columna derivada (EN: Derived column)
- **Definición:** Columna nueva creada a partir de otra mediante una operación, como comparar un monto con un umbral.
- **Categoría:** técnica
- **Módulo:** DF-M04
- **Relacionado:** Refinación de datos, Hipótesis

### Committer (EN: Committer)
- **Definición:** Persona que revisa y aprueba cambios y tiene permiso de escritura en el repositorio.
- **Categoría:** concepto
- **Módulo:** DF-M03
- **Relacionado:** Colaborador, Repositorio

### Comprensión del negocio (EN: Business understanding)
- **Definición:** Primer paso de un proyecto: entender el problema de negocio, los objetivos y los requisitos antes de explorar datos.
- **Categoría:** buena práctica
- **Módulo:** DF-M02
- **Relacionado:** Patrocinador empresarial, Pensamiento de diseño, CRISP-DM

### Comunidad (EN: Community)
- **Definición:** Grupo de personas relacionadas con un proyecto de código abierto que obtienen beneficio de él.
- **Categoría:** concepto
- **Módulo:** DF-M03
- **Relacionado:** Código abierto, Colaborador

### Conjunto de datos (EN: Dataset)
- **Definición:** Colección de registros en filas y columnas, como el CSV de reclamaciones del proyecto.
- **Categoría:** concepto
- **Módulo:** DF-M04
- **Relacionado:** Archivo CSV, Datos estructurados

### Conjunto de entrenamiento (EN: Training set)
- **Definición:** Datos con respuestas conocidas con los que un modelo supervisado aprende patrones.
- **Categoría:** concepto
- **Módulo:** DF-M04
- **Relacionado:** Aprendizaje supervisado, Entrenamiento de modelos

### Conocimiento de la industria (EN: Domain knowledge)
- **Definición:** Conocimiento de un sector (salud, TI) que los empleadores valoran junto con las habilidades de datos.
- **Categoría:** concepto
- **Módulo:** DF-M05
- **Relacionado:** Habilidades laborales

### Consulta (EN: Query)
- **Definición:** Pregunta o instrucción dirigida a una base de datos para obtener o modificar su contenido.
- **Categoría:** concepto
- **Módulo:** DF-M03
- **Relacionado:** SQL

### Control de versiones (EN: Version control)
- **Definición:** Sistema que registra los cambios en el código fuente y coordina el trabajo de varias personas.
- **Categoría:** herramienta
- **Módulo:** DF-M03
- **Relacionado:** Git, Repositorio

### Conversión de tipo de columna (EN: Column type conversion)
- **Definición:** Cambio del tipo de dato de una columna (por ejemplo, cadena a fecha o booleano a entero) para poder hacer cálculos.
- **Categoría:** técnica
- **Módulo:** DF-M04
- **Relacionado:** Tipo de datos, Cadena, Booleano

### Correlación (EN: Correlation)
- **Definición:** Relación, normalmente lineal, entre dos variables aleatorias.
- **Categoría:** concepto
- **Módulo:** DF-M01
- **Relacionado:** Gráfico de dispersión

### CRISP-DM (EN: Cross-Industry Standard Process for Data Mining)
- **Definición:** Metodología iterativa de seis fases que parte de la comprensión del negocio.
- **Categoría:** técnica
- **Módulo:** DF-M02
- **Relacionado:** KDD, SEMMA, Minería de datos

### Datos (EN: Data)
- **Definición:** Información en bruto (hechos, estadísticas, opiniones, imágenes, voz) registrada en algún formato.
- **Categoría:** concepto
- **Módulo:** DF-M01
- **Relacionado:** Datos estructurados, Datos no estructurados

### Datos continuos (EN: Continuous data)
- **Definición:** Datos cuantitativos que pueden tomar infinitos valores y dividirse en decimales.
- **Categoría:** tipo de dato
- **Módulo:** DF-M01
- **Relacionado:** Datos discretos, Datos cuantitativos

### Datos cualitativos (EN: Qualitative data)
- **Definición:** Datos categóricos que describen cualidades con lenguaje en lugar de números.
- **Categoría:** tipo de dato
- **Módulo:** DF-M01
- **Relacionado:** Datos nominales, Datos ordinales, Datos cuantitativos

### Datos cuantitativos (EN: Quantitative data)
- **Definición:** Datos numéricos que se cuentan o miden.
- **Categoría:** tipo de dato
- **Módulo:** DF-M01
- **Relacionado:** Datos discretos, Datos continuos, Datos cualitativos

### Datos de identificación (EN: Identifier data)
- **Definición:** Columnas de ID que solo distinguen registros y no sirven para predecir comportamientos.
- **Categoría:** tipo de dato
- **Módulo:** DF-M04
- **Relacionado:** Datos predictivos, Preparación de datos

### Datos discretos (EN: Discrete data)
- **Definición:** Datos cuantitativos enteros e indivisibles, resultado de contar unidades completas.
- **Categoría:** tipo de dato
- **Módulo:** DF-M01
- **Relacionado:** Datos continuos, Datos cuantitativos

### Datos estructurados (EN: Structured data)
- **Definición:** Datos organizables en filas y columnas, aptos para bases de datos y hojas de cálculo.
- **Categoría:** tipo de dato
- **Módulo:** DF-M01, DF-M02, DF-M03, DF-M04
- **Relacionado:** Base de datos, SQL, Datos no estructurados

### Datos no estructurados (EN: Unstructured data)
- **Definición:** Datos sin formato predefinido, guardados en su forma original (texto, imágenes, redes sociales).
- **Categoría:** tipo de dato
- **Módulo:** DF-M01, DF-M02, DF-M03, DF-M04, DF-M05
- **Relacionado:** Datos estructurados, Variedad

### Datos nominales (EN: Nominal data)
- **Definición:** Datos cualitativos que etiquetan categorías sin orden ni jerarquía.
- **Categoría:** tipo de dato
- **Módulo:** DF-M01
- **Relacionado:** Datos ordinales, Datos cualitativos

### Datos ordenados (EN: Tidy data)
- **Definición:** Datos transformados a un formato estándar que facilita su almacenamiento y análisis.
- **Categoría:** buena práctica
- **Módulo:** DF-M01, DF-M02
- **Relacionado:** Datos estructurados, Base de datos

### Datos ordinales (EN: Ordinal data)
- **Definición:** Datos cualitativos con categorías ordenadas según su posición en una escala.
- **Categoría:** tipo de dato
- **Módulo:** DF-M01
- **Relacionado:** Datos nominales, Datos cualitativos

### Datos oscuros (EN: Dark data)
- **Definición:** Datos no estructurados, como imágenes y texto, con los que colabora el científico de datos.
- **Categoría:** tipo de dato
- **Módulo:** DF-M05
- **Relacionado:** Datos no estructurados

### Datos predictivos (EN: Predictive data)
- **Definición:** Datos de una columna que pueden ayudar a predecir el resultado de interés, como el fraude.
- **Categoría:** concepto
- **Módulo:** DF-M04
- **Relacionado:** Datos de identificación, Desviación estándar

### Datos ruidosos (EN: Noisy data)
- **Definición:** Datos poco útiles que hay que filtrar para encontrar lo relevante.
- **Categoría:** concepto
- **Módulo:** DF-M01, DF-M04
- **Relacionado:** Valor, Veracidad, Calidad de los datos

### Decisiones basadas en datos (EN: Data-driven decision making)
- **Definición:** Práctica de decidir apoyándose en información extraída de los datos.
- **Categoría:** buena práctica
- **Módulo:** DF-M01
- **Relacionado:** Análisis de datos, Narración de datos

### Desviación estándar (EN: Standard deviation)
- **Definición:** Medida de cómo se dispersan los datos respecto a la media.
- **Categoría:** métrica
- **Módulo:** DF-M02, DF-M04
- **Relacionado:** Media, Estadística descriptiva

### Enfoque analítico (EN: Analytical approach)
- **Definición:** Planteamiento del problema de negocio en términos de técnicas estadísticas o de machine learning.
- **Categoría:** concepto
- **Módulo:** DF-M02
- **Relacionado:** Regresión logística, Comprensión del negocio

### Entero (EN: Integer)
- **Definición:** Tipo de dato numérico sin decimales; también puede codificar 0 o 1 para no o sí.
- **Categoría:** tipo de dato
- **Módulo:** DF-M04
- **Relacionado:** Booleano, Tipo de datos

### Entorno de desarrollo integrado (EN: Integrated development environment (IDE))
- **Definición:** Plataforma que reúne herramientas de desarrollo y análisis, como IBM Watson Studio o RStudio.
- **Categoría:** herramienta
- **Módulo:** DF-M03, DF-M04
- **Relacionado:** IBM Watson Studio, RStudio

### Entrenamiento de modelos (EN: Model training)
- **Definición:** Proceso en que un algoritmo de machine learning aprende de los datos para mejorar su precisión.
- **Categoría:** técnica
- **Módulo:** DF-M02
- **Relacionado:** Modelo de datos, Aprendizaje supervisado

### Estadística descriptiva (EN: Descriptive statistics)
- **Definición:** Resumen cuantitativo de un conjunto de datos mediante medidas como media, mediana, moda y desviación estándar.
- **Categoría:** métrica
- **Módulo:** DF-M02, DF-M04
- **Relacionado:** Media, Mediana, Moda, Análisis descriptivo

### ETL (EN: Extract, Transform, Load)
- **Definición:** Proceso que extrae datos de varias fuentes, los transforma y los carga en un almacén o sistema destino consistente.
- **Categoría:** técnica
- **Módulo:** DF-M01
- **Relacionado:** Almacén de datos, Sistema heredado, Calidad de los datos

### Exploración de datos (EN: Data exploration)
- **Definición:** Revisión inicial de un conjunto de datos para hallar patrones, relaciones y características prometedoras.
- **Categoría:** técnica
- **Módulo:** DF-M02
- **Relacionado:** Preparación de datos, Visualización exploratoria

### Fraude (EN: Fraud)
- **Definición:** Reclamación engañosa que genera pérdidas a la empresa; en el caso del módulo, lo que se busca predecir.
- **Categoría:** concepto
- **Módulo:** DF-M04
- **Relacionado:** Reclamación de seguro, Conjunto de entrenamiento

### Frecuencia (EN: Frequency)
- **Definición:** Número de veces que ocurre un evento.
- **Categoría:** concepto
- **Módulo:** DF-M01
- **Relacionado:** Gráfico de columnas, Gráfico de líneas

### ggplot2 (EN: ggplot2)
- **Definición:** Paquete de R para visualización de datos.
- **Categoría:** herramienta
- **Módulo:** DF-M03
- **Relacionado:** R, RStudio

### Git (EN: Git)
- **Definición:** Sistema de control de versiones de código abierto que se instala localmente.
- **Categoría:** herramienta
- **Módulo:** DF-M03
- **Relacionado:** GitHub, Repositorio, Control de versiones

### GitHub (EN: GitHub)
- **Definición:** Servicio en línea para alojar código y colaborar en repositorios; requiere Git.
- **Categoría:** herramienta
- **Módulo:** DF-M03
- **Relacionado:** Git, Repositorio

### Gráfico circular (EN: Pie chart)
- **Definición:** Gráfico dividido en secciones que suman 100 %, para mostrar la proporción relativa de pocos elementos.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02
- **Relacionado:** Proporción relativa, Visualización de datos

### Gráfico de barras (EN: Bar chart)
- **Definición:** Gráfico para comparar y clasificar categorías y mostrar cambios en el tiempo.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02
- **Relacionado:** Gráfico de columnas, Categoría (comparación)

### Gráfico de columnas (EN: Column chart)
- **Definición:** Gráfico vertical útil para proporciones, datos en el tiempo, frecuencia y valores negativos.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02
- **Relacionado:** Gráfico de barras, Frecuencia

### Gráfico de dispersión (EN: Scatter plot)
- **Definición:** Gráfico de puntos que muestra la relación entre dos conjuntos de datos y resalta valores atípicos.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02, DF-M04
- **Relacionado:** Correlación, Valor atípico

### Gráfico de líneas (EN: Line chart)
- **Definición:** Gráfico que muestra datos continuos en el tiempo y destaca tendencias y cambios pequeños.
- **Categoría:** técnica
- **Módulo:** DF-M01, DF-M02
- **Relacionado:** Serie temporal, Frecuencia

### Habilidades laborales (EN: Soft skills)
- **Definición:** Habilidades como comunicación, trabajo en equipo, pensamiento crítico e inteligencia emocional; también llamadas de empleabilidad, sociales o profesionales.
- **Categoría:** concepto
- **Módulo:** DF-M05
- **Relacionado:** Conocimiento de la industria

### Habilidades técnicas (EN: Hard skills)
- **Definición:** Capacidades específicas del puesto, como análisis de datos, ciencia de datos y manejo de herramientas y lenguajes como SQL o Python.
- **Categoría:** concepto
- **Módulo:** DF-M05
- **Relacionado:** Habilidades laborales, Python, SQL

### Hipótesis (EN: Hypothesis)
- **Definición:** Suposición inicial que se plantea y se pone a prueba con los datos; puede cambiar tras la exploración.
- **Categoría:** concepto
- **Módulo:** DF-M02, DF-M04, DF-M05
- **Relacionado:** Método científico, Exploración de datos

### Hoja de cálculo (EN: Spreadsheet)
- **Definición:** Herramienta para organizar datos estructurados en filas y columnas (Google Sheets, Microsoft Excel).
