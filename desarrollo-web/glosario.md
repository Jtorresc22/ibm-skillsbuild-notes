# Glosario

### Abstracción (EN: abstraction)
- **Definición:** Ocultar la complejidad de la máquina para poder dar instrucciones sin conocer los detalles internos.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Lenguaje de programación, Código binario

### Accesibilidad (EN: accessibility)
- **Definición:** Capacidad de un sitio de ofrecer buena experiencia a todos los usuarios, incluidos los que usan tecnología de asistencia. El modelo de cuadro CSS la favorece frente a las tablas de maquetación.
- **Categoría:** buena práctica
- **Módulo:** M01, M03, M07
- **Relacionado:** Diseño web reactivo, Diseño web, Lector de pantalla, aria-label, Modelo de cuadro CSS, Front-end, QA

### Actividad del lado del cliente (EN: client-side activity)
- **Definición:** Trabajo que genera el usuario o el explorador, como enviar una solicitud o mostrar la página recibida.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Solicitud, Actividad del lado del servidor, Explorador

### Actividad del lado del servidor (EN: server-side activity)
- **Definición:** Trabajo que realiza el servidor al detectar una solicitud, como enviar una página web al cliente.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Servidor web, Node.js, Actividad del lado del cliente

### Almacenamiento a corto plazo (EN: short-term storage)
- **Definición:** Memoria volátil que guarda datos solo mientras el dispositivo funciona; es la RAM.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Memoria de acceso aleatorio, Almacenamiento a largo plazo

### Almacenamiento a largo plazo (EN: long-term storage)
- **Definición:** Almacenamiento que conserva la información aunque se apague el dispositivo (SSD, HDD).
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Unidad de disco duro, Unidad de estado sólido, Cookie

### ALTER (EN: ALTER)
- **Definición:** Mandato DDL que modifica bases de datos o tablas existentes, por ejemplo añadiendo o quitando columnas.
- **Categoría:** lenguaje
- **Módulo:** M04
- **Relacionado:** DDL, CREATE, DROP

### Analizador (EN: parser)
- **Definición:** Software, normalmente parte del explorador, que examina el texto de un documento, separa sus elementos y aplica el formato según las etiquetas.
- **Categoría:** herramienta
- **Módulo:** M02, M03
- **Relacionado:** explorador web, representación, HTML, Marcado, Representación, Explorador web

### Ancho de banda (EN: bandwidth)
- **Definición:** Cantidad de datos que una red puede transmitir en un periodo; es un recurso limitado.
- **Categoría:** concepto
- **Módulo:** M02
- **Relacionado:** marcado, incrustación, cantidad

### Ancla (EN: anchor element (a))
- **Definición:** Elemento que enlaza con otro documento o recurso; necesita atributos adicionales como href.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M03
- **Relacionado:** href, Atributo, Hiperenlace

### Angular (EN: Angular)
- **Definición:** Marco JavaScript citado como ejemplo de los usados por grandes sitios.
- **Categoría:** herramienta
- **Módulo:** M04, M07
- **Relacionado:** Marco, React, Vue.js, marco

### Anidamiento (EN: nesting)
- **Definición:** Colocar elementos HTML dentro de otros, lo que da estructura al documento y establece relaciones padre-hijo.
- **Categoría:** concepto
- **Módulo:** M03
- **Relacionado:** Elemento padre y elemento hijo, Herencia

### API (EN: API (application programming interface))
- **Definición:** Interfaz de programación de aplicaciones; vía por la que un sitio usa software o servicios externos, por ejemplo en la nube.
- **Categoría:** concepto
- **Módulo:** M01, M05
- **Relacionado:** Llamada de API, Computación en la nube, Método GET, Método POST, Postman

### Aplicación de propiedad (EN: proprietary application)
- **Definición:** Aplicación de código cerrado salvo para quien la creó; solo quien la posee puede abrir sus documentos.
- **Categoría:** concepto
- **Módulo:** M02
- **Relacionado:** apertura, código abierto, marcado

### Aplicación nativa (EN: native app)
- **Definición:** Aplicación móvil programada con lenguajes que interactúan directamente con el sistema operativo del dispositivo.
- **Categoría:** concepto
- **Módulo:** M05
- **Relacionado:** Aplicación web, Wrapper de aplicaciones

### Aplicación web (EN: web application)
- **Definición:** Sitio web que se comporta como una aplicación, se entrega en línea y se ejecuta en el explorador; puede instalarse como híbrido.
- **Categoría:** concepto
- **Módulo:** M01, M02, M05
- **Relacionado:** Wrapper, Página web, Explorador web, HTML5, explorador web, marcos, Wrapper de aplicaciones, Diseño reactivo

### Archivo .js (EN: JavaScript file (.js))
- **Definición:** Archivo de texto plano con extensión .js que contiene código JavaScript externo.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Atributo src, Elemento script, IDE

### Área de contenido (EN: content area)
- **Definición:** Espacio dentro del cuadro donde está el contenido principal; tiene altura y anchura.
- **Categoría:** concepto
- **Módulo:** M03
- **Relacionado:** Modelo de cuadro CSS, Relleno, Borde

### aria-label (EN: aria-label)
- **Definición:** Atributo que asigna un nombre o etiqueta a un elemento para tecnología de asistencia como los lectores de pantalla.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M03
- **Relacionado:** Accesibilidad, Atributo

### Arquitectura de la información (EN: information architecture)
- **Definición:** Método para organizar, estructurar y etiquetar el contenido de modo que los usuarios encuentren información y completen tareas.
- **Categoría:** concepto
- **Módulo:** M02, M03
- **Relacionado:** mapa del sitio, estructura de navegación, SDLC, Elementos semánticos, Listas, Arquitectura de información

### Asignación (EN: assignment)
- **Definición:** Operación que rellena una variable con un valor mediante el signo igual.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Variable, Operador, Expresión

### Atributo (EN: attribute)
- **Definición:** Dato adicional dentro de una etiqueta de apertura que da al explorador información para dar formato o acción al elemento.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M02, M03
- **Relacionado:** elemento, etiqueta, style, href, onclick, Etiqueta, id, class

### Atributo class (EN: class attribute)
- **Definición:** Atributo HTML que sirve como selector de estilo y puede aplicarse a uno o varios elementos.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M06
- **Relacionado:** Atributo id, Selector de clase, Selector encadenado

### Atributo id (EN: id attribute)
- **Definición:** Atributo HTML que identifica un elemento concreto y se usa como selector de estilo.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M06
- **Relacionado:** Atributo class, Selector de ID

### Atributo src (EN: src attribute)
- **Definición:** Atributo del elemento script que indica el nombre del archivo JavaScript externo que se carga.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M04
- **Relacionado:** Elemento script, Archivo .js, JavaScript

### Atributos de evento (EN: event attributes (onclick, onerror, onkeypress, onscroll))
- **Definición:** Atributos que ejecutan una función de script ante un suceso: clic, error, tecla pulsada o desplazamiento por la página.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M03
- **Relacionado:** Evento, Script, Atributo

### Autenticación (EN: authentication)
- **Definición:** Verificación de la identidad del usuario comparando sus datos con la información almacenada de su cuenta.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Autenticación de dos factores, Base de datos, Cifrado

### Autenticación de dos factores (2FA) (EN: two-factor authentication (2FA))
- **Definición:** Verificación que exige, además de usuario y contraseña, un dispositivo móvil o una aplicación de autenticación.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Autenticación, Herencia, Objeto de código

### Autodescriptivo (EN: self-descriptive)
- **Definición:** Dicho de un elemento cuyo nombre indica su finalidad o contenido.
- **Categoría:** concepto
- **Módulo:** M03
- **Relacionado:** Elementos semánticos

### autofocus (EN: autofocus)
- **Definición:** Atributo que indica al explorador que el elemento debe recibir el foco al cargar la página.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M03
- **Relacionado:** Atributo, href

### Back-end (desarrollador) (EN: Back-end developer)
- **Definición:** Rol que gestiona datos, seguridad, APIs y lógica del servidor con lenguajes como Python, Java o JavaScript.
- **Categoría:** concepto
- **Módulo:** M07
- **Relacionado:** Front-end, Full-stack, API

### Backlog (EN: backlog)
- **Definición:** Lista priorizada de características y funciones que el equipo debe construir en la próxima versión.
- **Categoría:** concepto
- **Módulo:** M05
- **Relacionado:** DevOps, Planificación

### Backlog de sprint (EN: sprint backlog)
- **Definición:** Registro del trabajo que debe completarse pero aún no se ha iniciado.
- **Categoría:** concepto
- **Módulo:** M02
- **Relacionado:** Scrum, sprint, planificación de sprint

### Base de datos (EN: database)
- **Definición:** Colección estructurada de datos, normalmente almacenada en un ordenador o servidor y formada por tablas relacionadas.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Tabla, Registro, SQL, CRUD

### Bibliotecas (EN: library)
- **Definición:** Conjunto de código de función limitada que se conecta a una aplicación y se llama bajo demanda.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Marco, Dependencia, npm, jQuery

### Bibliotecas de código abierto (EN: open source libraries)
- **Definición:** Conjuntos de código de uso y modificación gratuitos que aportan interactividad al sitio y se referencian desde la cabecera.
- **Categoría:** herramienta
- **Módulo:** M03
- **Relacionado:** Script, Elemento head

### Bicapitalización (EN: camel case)
- **Definición:** Convención que omite espacios y pone mayúscula inicial en cada palabra tras el primer término; se usa en nombres de columna.
- **Categoría:** buena práctica
- **Módulo:** M02, M03, M04
- **Relacionado:** selector de clase, nombre de estilo, CSS, Estilo kebab, Notación con puntos, Convención de estilo de código, MySQL, Tabla, Variable

### Bit (EN: bit)
- **Definición:** Dígito binario con dos estados posibles (0/1, apagado/encendido); la unidad del lenguaje de máquina.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Código binario, Lenguaje de máquina

### Blob (EN: blob (binary large object))
- **Definición:** Archivo grande con datos binarios, como imágenes o vídeos, que la nube almacena y distribuye de forma optimizada.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Computación en la nube, Código binario

### Blockchain (EN: Blockchain)
- **Definición:** Libro mayor compartido e inalterable para registrar transacciones y rastrear activos y datos.
- **Categoría:** concepto
- **Módulo:** M07
- **Relacionado:** NFT, Metaverso, Cadena de suministro

### Bloque de cita (EN: blockquote)
- **Definición:** Elemento que contiene el texto de una cita de otra fuente.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M03
- **Relacionado:** Párrafo

### Bloque de declaración (EN: declaration block)
- **Definición:** Parte de una regla CSS entre llaves que contiene uno o varios estilos formados por propiedad y valor.
- **Categoría:** concepto
- **Módulo:** M02, M03
- **Relacionado:** selector, CSS, propiedad, Declaración, Selector

### Bloqueo (EN: blocking)
- **Definición:** Situación en que una tarea lenta en segundo plano impide que el servidor acepte otras solicitudes; Node.js es sin bloqueo.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Node.js, Servidor web, Solicitud

### Body, sección (EN: body section)
- **Definición:** Parte del documento HTML con el contenido principal visible en el explorador.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M02
- **Relacionado:** head, html

### Booleano (EN: boolean)
- **Definición:** Tipo de dato que solo puede ser verdadero o falso.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Tipo de datos, Tipo primitivo, Número, Cadena

### Bootstrap (EN: Bootstrap)
- **Definición:** Marco gratuito y de código abierto, basado en CSS y JavaScript, para crear sitios reactivos.
- **Categoría:** herramienta
- **Módulo:** M01, M05, M07
- **Relacionado:** Marco, React, Vue.js, Diseño reactivo, CSS, Biblioteca

### Borde (EN: border)
- **Definición:** Línea visible alrededor del cuadro; si no se define, no hay borde.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M03
- **Relacionado:** Modelo de cuadro CSS, Márgenes, Relleno

### Buena práctica (EN: best practice)
- **Definición:** Forma definida de realizar una tarea que garantiza coherencia, previsibilidad y calidad; puede fijarse a nivel de equipo o de sector.
- **Categoría:** buena práctica
- **Módulo:** M03
- **Relacionado:** Estándar, Convención de estilo de código

### C (EN: C)
- **Definición:** Lenguaje compilado muy común, valorado por combinar legibilidad de alto nivel con funciones de bajo nivel.
- **Categoría:** lenguaje
- **Módulo:** M01
- **Relacionado:** Lenguaje compilado, Java, C#, C

### Cadena (EN: string)
- **Definición:** Dato de texto; en JavaScript se pueden unir cadenas con el operador más.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Concatenación, Tipo de datos, varchar

### Captación (EN: fetch)
- **Definición:** Paso que trae a la máquina local los cambios más recientes de los archivos principales del repositorio.
- **Categoría:** concepto
- **Módulo:** M05
- **Relacionado:** Clonación, Repositorio de código

### Cascada (EN: cascade)
- **Definición:** Comportamiento por el cual un elemento hijo hereda estilos de sus padres y puede añadir o sustituir los suyos.
- **Categoría:** concepto
- **Módulo:** M03
- **Relacionado:** Herencia, Sustitución de estilos, CSS

### Cascada de CSS (EN: CSS cascade)
- **Definición:** Característica por la que los elementos hijo heredan el estilo de sus padres salvo que lo sustituyan con otro valor.
- **Categoría:** concepto
- **Módulo:** M02
- **Relacionado:** elemento padre, elemento hijo, herencia, CSS

### Cascada, método en (EN: waterfall method)
- **Definición:** Enfoque del SDLC en que las fases fluyen en secuencia descendente; es lento, implica poco al usuario y pospone las pruebas.
- **Categoría:** concepto
- **Módulo:** M02
- **Relacionado:** SDLC, metodología ágil

### Caso de prueba (EN: test case)
- **Definición:** Serie de pasos para verificar que una función o área del sitio opera correctamente.
- **Categoría:** concepto
- **Módulo:** M05
- **Relacionado:** Script de automatización, Entorno de pruebas

### Cifrado (EN: encryption)
- **Definición:** Forma de proteger información para que solo el software que lo usa pueda verla; un método cifrado puede encapsularse.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Encapsulación, Autenticación

### class (EN: class)
- **Definición:** Atributo que referencia un estilo de clase de una hoja de estilo; puede usarse en muchos elementos.
- **Categoría:** etiqueta o propiedad
- **Módulo:** M03
- **Relacionado:** Selector de clase, id

### CLI (interfaz de línea de mandatos) (EN: CLI (Command Line Interface))
- **Definición:** Programa del sistema que permite ejecutar mandatos escribiéndolos; se llama Terminal en Mac y línea de comandos en Windows.
- **Categoría:** herramienta
- **Módulo:** M04
- **Relacionado:** GUI, MySQL

### Clonación (EN: clone)
- **Definición:** Copiar un repositorio completo a la máquina local para trabajar sin tocar los archivos principales.
- **Categoría:** concepto
- **Módulo:** M05
- **Relacionado:** Captación, Repositorio de código

### Código autodescriptivo (EN: self-describing code)
- **Definición:** Código cuya sintaxis indica al desarrollador qué hace, además de ser legible.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Lenguaje interpretado, Sintaxis

### Código binario (EN: binary code)
- **Definición:** También llamado código de máquina; representa todos los datos con ceros y unos y es el único lenguaje que entiende el ordenador.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Bit, Lenguaje de máquina, Compilador

### Código espagueti (EN: spaghetti code)
- **Definición:** Código no estructurado con muchas rutas y bucles posibles, típico del uso de goto, difícil de seguir y mantener.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Sentencia goto, Programación procedimental, Objeto de código

### Código fuente (EN: source code)
- **Definición:** Versión del programa que los desarrolladores pueden leer y editar antes de compilarlo o interpretarlo.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Compilador, Intérprete

### Comentarios en el código (EN: code comments)
- **Definición:** Anotaciones que delimitan secciones, documentan o guardan pendientes; no se muestran en la página pero sí en el código fuente.
- **Categoría:** buena práctica
- **Módulo:** M03
- **Relacionado:** Convención de estilo de código

### Comercio electrónico (EN: e-commerce)
- **Definición:** Compra y venta mediante tiendas en línea, posible gracias al desarrollo web.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Sitio web, Desarrollo web

### Compatibilidad con versiones anteriores (EN: backward compatibility)
- **Definición:** Capacidad de un lenguaje de admitir tanto los métodos antiguos como los nuevos; explica por qué JavaScript ofrece varias formas de hacer lo mismo.
- **Categoría:** concepto
- **Módulo:** M02
- **Relacionado:** JavaScript, ECMAScript

### Competencias laborales (EN: Soft skills)
- **Definición:** Aptitudes no técnicas (comunicación, trabajo en equipo, pensamiento crítico, empatía); también llamadas blandas, de empleabilidad o profesionales.
- **Categoría:** concepto
- **Módulo:** M07
- **Relacionado:** Comunicación, Escucha activa, Competencias técnicas

### Compilación (EN: build)
- **Definición:** Conjunto de cambios de un sitio web listos para entregarse al usuario.
- **Categoría:** concepto
- **Módulo:** M05
- **Relacionado:** Despliegue continuo, Entrega continua

### Compilador (EN: compiler)
- **Definición:** Software que convierte el código fuente legible en código de máquina; la compilación suele ser unidireccional.
- **Categoría:** herramienta
- **Módulo:** M01
- **Relacionado:** Código fuente, Lenguaje compilado, Intérprete

### Computación en la nube (EN: cloud computing)
- **Definición:** Evolución de las granjas de servidores que separa funciones (almacenamiento, proceso, redes) en servidores dedicados usados bajo demanda.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Granja de servidores, Escalado, Llamada de API

### Concatenación (EN: concatenation)
- **Definición:** Unión de cadenas de texto mediante el operador más para formar una nueva cadena.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Cadena, Operador, Expresión

### Confirmación (EN: commit)
- **Definición:** Registro de los cambios hechos desde el último commit, acompañado de un mensaje breve que los describe.
- **Categoría:** concepto
- **Módulo:** M05
- **Relacionado:** Push, Solicitud de extracción

### Conformidad con la normativa (EN: compliance)
- **Definición:** Garantía de que el sitio cumple las leyes aplicables, sobre todo en sectores regulados como salud y finanzas.
- **Categoría:** buena práctica
- **Módulo:** M05
- **Relacionado:** Shift left, DevOps

### const (EN: const)
- **Definición:** Palabra clave que declara una variable de valor inmutable durante la ejecución.
- **Categoría:** lenguaje
- **Módulo:** M04
- **Relacionado:** let, var, Constante, Inmutable

### Constante (EN: constant)
- **Definición:** Miembro de un objeto que contiene datos que no cambian mientras el programa se ejecuta.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Miembro, Propiedad, const

### Contenedor (EN: container)
- **Definición:** Paquete estandarizado con código, entorno de ejecución, bibliotecas, herramientas del sistema y configuración; usa solo las partes necesarias del sistema operativo.
- **Categoría:** concepto
- **Módulo:** M05
- **Relacionado:** Máquina virtual, Microservicio

### Contenerización (EN: Containerization)
- **Definición:** Servicios para empaquetar y ejecutar aplicaciones en contenedores; se citan Docker y Kubernetes.
- **Categoría:** concepto
- **Módulo:** M07
- **Relacionado:** Docker, Kubernetes, DevOps

### Control de versiones (EN: version control)
- **Definición:** Sistema que registra y gestiona los cambios del código, indicando quién, qué, dónde, cuándo y por qué.
- **Categoría:** herramienta
- **Módulo:** M05
- **Relacionado:** Repositorio de código, SCCS

### Convención de estilo de código (EN: code style convention)
- **Definición:** Regla de equipo sobre cómo escribir ciertos objetos de código para mantener un patrón coherente.
- **Categoría:** buena práctica
- **Módulo:** M03
- **Relacionado:** Bicapitalización, Estilo kebab, Notación con puntos

### Conversión de tipo implícito (EN: implicit type conversion)
- **Definición:** Decisión de JavaScript en ejecución sobre qué operación o tipo aplicar según los datos de las variables.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** Lenguaje débilmente tipado, Operador, Variable

### Cookie (EN: cookie)
- **Definición:** Pequeño archivo que un sitio guarda en el dispositivo con datos del usuario y que persiste entre sesiones.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Sesión, Almacenamiento a largo plazo

### CPU (EN: CPU (central processing unit))
- **Definición:** Unidad central de proceso; interpreta directamente el código de máquina y maneja el proceso.
- **Categoría:** concepto
- **Módulo:** M01
- **Relacionado:** Hardware, Código binario

### CREATE (EN: CREATE)
- **Definición:** Mandato DDL que crea bases de datos, tablas y otros elementos.
- **Categoría:** lenguaje
- **Módulo:** M04
- **Relacionado:** DDL, ALTER, DROP

### CRUD (EN: CRUD)
- **Definición:** Las cuatro operaciones principales de una base de datos: crear, leer, actualizar y suprimir.
- **Categoría:** concepto
- **Módulo:** M04
- **Relacionado:** SQL, INSERT, SELECT, UPDATE, DELETE

### CSS (EN: CSS (Cascading Style Sheets))
